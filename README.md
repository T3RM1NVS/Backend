# Greetings

To properly work with this shoddily made repo you must follow a few basic steps:

1. This repo has a virtual environment, so dependencies are not an issue.
2. Install PostgreSQL-17.
3. If it is your first time, run `initdb.py`.
4. After that, run `runapp.py`.
5. Open `localhost:8000/docs` to see the SwaggerUI.
